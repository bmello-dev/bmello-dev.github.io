Privacy Policy — NSN V1.X Sandbox Deployment

Effective October 7, 2026. Operator: Brandyn Mello.

Purpose and Google permissions

This private, personal-use tool is designed solely to maintain an approved Google Apps Script sandbox application's source and deployment versions.

It requests only these Google OAuth scopes:

  • https://www.googleapis.com/auth/script.projects — manage Apps Script project source and versions.
  • https://www.googleapis.com/auth/script.deployments — manage Apps Script deployments.

Google grants these permissions at the account level, not for a single project. The tool is designed to restrict its operations to the approved sandbox target. The credential must not be used for other projects.

Data accessed and use

The tool accesses Apps Script source, project/version metadata, and deployment metadata only as necessary to prepare, publish, and verify sandbox deployments. It receives OAuth credentials needed for those operations. It does not request Google Sheets, Drive, or Calendar data permissions and is not used to read CRM records.

Storage and service providers

Apps Script source and deployment verification records are retained privately for maintenance and audit. The local authorization bootstrap transfers the OAuth client credential and refresh token directly into encrypted GitHub secret storage. They are not published on this website, committed to repository source, or intentionally written into logs. Access tokens are used transiently for authorized Google API requests.

Google provides authorization and Apps Script services. GitHub provides private source storage, encrypted secret storage, and deployment automation. Google-derived information is used through these providers only to support the stated deployment purpose.

Retention and revocation

Authorization credentials are retained only while the deployment capability is needed. Brandyn can revoke the application's access in his Google Account's third-party connections settings and remove the associated GitHub secrets. Revocation stops further authorized access but does not automatically delete previously retained source or verification records. Requests concerning retained data should be directed to the operator.

Limits on use

Google user data is not sold, used for advertising, or used to train artificial intelligence models. It is not shared with third parties for unrelated purposes.

NSN V1.X Sandbox Deployment's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

This public site

This website is informational only. It contains no forms, application authentication, analytics scripts, or deployment controls. Its hosting provider may process ordinary request information according to its own privacy policy.

Questions

Contact Brandyn Mello using the support email displayed on this application's Google OAuth consent screen.
