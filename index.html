NSN V1.X Sandbox Deployment

NSN V1.X Sandbox Deployment is a private, personal-use development tool operated by Brandyn Mello. It is designed to maintain the source and deployment versions of an approved Google Apps Script sandbox application.

The tool requests Google authorization only to manage Apps Script projects and deployments. It does not request Google Sheets, Drive, or Calendar data permissions.

This public website provides OAuth application information only. It does not provide sign-in, deployment controls, or access to business records.
